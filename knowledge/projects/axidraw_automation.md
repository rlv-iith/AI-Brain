# AxiDraw Lab Automation — ElectroChem Research (IITH)

**Category:** Robotics / Hardware + Software  
**Context:** Research project at ElectroChem Materials Group, IITH  
**Stack:** Python, G-Code, Solid Edge, AxiDraw hardware

## What it does
Hacked an AxiDraw drawing machine to perform precise electrochemical deposition for fabricating micro-supercapacitor electrodes. The machine deposits conductive ink in exact patterns with ±0.005 inch precision.

## Technical work
- Wrote Python scripts to generate G-Code toolpaths for non-standard electrode geometries
- Integrated with Solid Edge CAD designs — CAD → G-Code pipeline was fully automated
- Built a feedback loop to detect deposition failures and retry
- Result: lab throughput increased by **30%**, experiment turnaround cut from days to hours

## Research contribution
This work contributed to a paper on micro-supercapacitors co-authored with PhD scholars — currently under review. The AxiDraw approach is now used as the standard deposition method in the lab.
